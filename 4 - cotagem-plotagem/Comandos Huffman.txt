Compilar :

gcc -O2 -Wall -Wextra -o huffman huffman.c

Compactar :

./huffman c arquivo
Descompactar

./huffman d arquivo.huff
./huffman d arquivo.huff arquivo volta

Conferir se voltou idêntico:

cmp arquivo arquivo_volta && echo IGUAIS

Conferir tamanho:

ls -l arquivo arquivo.huff arquivo volta

Conferir tempo:

time ./huffman c arquivo
time ./huffman d arquivo.huff arquivo_volta
